| 淹水区间迫停列车 | 视情启动区间乘客疏散。 |
涝水倒灌 | 车站倒灌 | 不具备向站外疏散条件，但具备使用列车疏散乘客，使用列车疏散乘客。 |
| | 由线路区间倒灌涌入车站，停站列车乘客及站内乘客向站外疏散。 |
| 线路倒灌 | 尽量防止列车停在线路最低点，防止停站列车驶入区间。 |
| | 若列车距离车站较近时，视情尽量驶入/退回车站。 |
| | 列车已迫停区间且严重危及乘客安全时，在确认具备安全条件情况（如接触轨断电、有逃生条件）下，启动乘客疏散。 |

备注 | 1、接报突发场景信息后，应立即做好相关列车截停、扣车等安全防护操作。
2、确认现场实际情况后，应及时发布抢修令，并配合抢修人员现场处置。
3、涉及限速运行时，应根据实际情况，发布对应的限速命令。
4、涉及线路中断时，区间内列车具备运行至前方站条件时，限速20km/h运行至前方站；不具备运行至前方站条件时，退回发车站或布置区间疏散。
5、涉及接触轨线路，应在布置区间疏散或人员进入接触轨线路前，做好接触轨断电防护工作。
6、根据突发事件处置进度，及时做好信息汇报流转工作。 | |
