## 已修复问题

1. 文件改为按 SHA-256 内容哈希去重，不再用“文件名 + 大小”猜测重复。
2. 丢弃无标题提示列后再次判空，移除灿都和轩岚诺各 1 条空事件。
3. 显式规定结构化 JSON 路径优先于传统路径表。
4. 补齐梅花编号 `202212`、英文名 `Muifa`；纠正普拉桑英文名为 `Pulasan`。
5. 梅花 1 条媒体宣传长文本从错误的时间列迁回内容列。
6. 普拉桑 2 条倒序时间不再伪造结束日期，结束时间按“未知”处理，并写入人工复核告警。
7. 导入脚本默认只预演；只有传入 `--apply` 才写数据库。
8. 非 `schooltyphoon` 库默认拒绝写入，隔离测试库必须显式传入 `--allow-other-database`。
9. 全量文档先在内存中验证；写入改为批量操作，单案例/单路径失败会恢复原数据。
10. 验收只统计本次案例和路径，不受数据库内其他资料影响；报告会隐藏 URI 中的账号密码。
11. cases 自动写入 `createdAt`、`updatedAt`，重复导入时保留原 `createdAt`。
12. 写入全新数据库时自动建立平台查询所需的 5 个索引。

## 安全使用方式

仅预演，不连接数据库：

```powershell
python -X utf8 import_cases_to_mongo.py
```

写入隔离测试库：

```powershell
python -X utf8 import_cases_to_mongo.py `
  --uri "mongodb://127.0.0.1:27017/schooltyphoon_codex_audit" `
  --apply `
  --allow-other-database
```

在本分支合并并得到人工确认前，不要对正式库执行 `--apply`。
