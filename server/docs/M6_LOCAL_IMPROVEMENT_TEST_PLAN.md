### 2.6 指标定义与金标准数据集（Codex 补充）

D7 的 10 问适合作为检索冒烟测试，但还没有“每道题哪些片段必须命中”的标准答案，因此不能单独证明准确率、精确率和召回率。M6 需要先建立带版本号的金标准数据集（gold set），再计算指标。

1. **准确率（Accuracy）**：全部有标准答案的判断中，系统完整答对的比例。例如工具选择、风险等级、时间窗口等离散判断。
2. **精确率（Precision）**：系统返回的结果中真正相关的比例，计算公式为 `TP / (TP + FP)`。误列不受影响线路属于 FP。
3. **召回率（Recall）**：所有应该返回的相关结果中被系统找到的比例，计算公式为 `TP / (TP + FN)`。遗漏相关知识片段属于 FN。
4. **F1**：精确率和召回率的综合指标，计算公式为 `2PR / (P + R)`。

**金标准最小规模：**

| 任务 | 最小样本 | 人工标准答案 |
|---|---:|---|
| 8 个智能体工具路由 | 每个工具至少 10 问，共 80 问 | 应调用的工具、参数、必须出现的回答字段、无数据时的正确行为 |
| 知识库检索 | 至少 50 问 | 每题 3–5 个相关 `chunkId/filePath`，相关度标为 0/1/2，并确认不含敏感内容 |
| 线路影响研判 | 至少 20 个历史或模拟轨迹场景 | 直接空间计算得到的线路集合、最高等级和时间窗口 |
| 相似案例匹配 | 至少 30 个 leave-one-out 场景 | 合理的 Top-1/Top-3 案例标签；不得用自匹配 1.0 代替区分能力 |
| 防编造与缺失数据 | 至少 30 个问题 | 应回答“未知/无记录”、应拒绝的内容和禁止出现的无依据结论 |

金标准只保存问题、非敏感标准答案和片段 ID，不复制敏感原文。建议由两名人员独立标注；不一致时由业务人员裁定并冻结版本。

**建议起始门槛（业务人员确认后冻结）：**

- 工具选择准确率 ≥ 95%；关键实时数据工具和必填参数必须 100% 正确。
- 知识库 `Precision@5 ≥ 0.80`、`Recall@5 ≥ 0.90`、`F1 ≥ 0.85`，敏感内容 0 命中。
- 线路影响 Precision/Recall/F1 ≥ 0.95；与同一空间计算结果比较时，线路集合、最高等级和时间窗口必须 100% 一致。
- 相似案例 `Top-3 Recall ≥ 0.80`、`MRR ≥ 0.70`，不得把低相似案例表述成已发生事实。
- 有来源回答的事实正确率 ≥ 95%；无来源具体事实、编造条款和编造人员信息均为 0。

每次评估必须记录：模型名称、模型服务、模型参数、Prompt 版本、Git 提交号、MongoDB/Qdrant 数据快照、问题集版本、原始命中 ID 和计算结果。只有使用同一金标准和同一数据快照，优化前后的指标才可比较。学校环境当前只有 1 份知识库文档，迁移并核对至批准的数据集之前，不得与本机 72/3002/3002 的检索指标直接比较。

QWEATHER/台风数据源不可用的题目单独标为“外部数据阻断”，不能把诚实回答“数据源不可用”算作模型答错；但也不能据此宣称实时台风准确率通过。凭据补齐后必须在真实数据源上重跑对应金标准题目。

## 七、范围外事项（记录发现，移交平台开发部门）

以下问题在实测中发现，**不属于本项目修复范围**（本项目不迁移相关改动），但记录于此供平台后续开发参考：
